# Definition of Done

Antes de considerar uma tarefa concluída:

[ ] Requisito atendido.
[ ] Diff revisado.
[ ] Sem arquivos irrelevantes alterados.
[ ] Tenant isolation preservado.
[ ] Autorização preservada.
[ ] Sem segredo ou token exposto.
[ ] Migration revisada quando aplicável.
[ ] Contratos consumidor/produtor verificados.
[ ] Limitações conhecidas documentadas.
