# Workflow: Correção de Bug

1. Reproduzir ou localizar evidência do problema.
2. Identificar comportamento esperado.
3. Localizar a causa, não apenas o sintoma.
4. Corrigir a causa com a menor mudança segura.
5. Adicionar ou ajustar teste quando apropriado.
6. Executar build/testes.
7. Verificar se a correção não viola tenant, autorização ou contratos.
8. Relatar causa raiz e correção.
