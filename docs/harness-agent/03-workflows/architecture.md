# Workflow: Decisão Arquitetural

Nunca introduza uma mudança arquitetural grande apenas por preferência.

Para cada proposta documente:

## Problema

Qual problema concreto existe?

## Contexto

Qual é a escala, restrição e estágio atual?

## Alternativas

Liste as alternativas plausíveis.

## Trade-offs

Compare:
- complexidade;
- custo;
- operação;
- manutenção;
- segurança;
- escalabilidade;
- impacto no time;
- reversibilidade.

## Decisão

Escolha a alternativa que melhor atende ao contexto atual.

## Consequência

Registre o que ficará mais fácil e mais difícil após a decisão.
