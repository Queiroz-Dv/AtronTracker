# Workflow: Nova Feature

## Fase 1 — Descoberta

- Ler arquivos relacionados.
- Identificar módulo.
- Identificar entidades.
- Identificar contratos.
- Procurar casos semelhantes.

## Fase 2 — Projeto

Definir:
- fluxo;
- regras;
- persistência;
- autorização;
- tenant;
- impactos no frontend/backend.

## Fase 3 — Implementação

Implementar a menor mudança que satisfaz o requisito.

## Fase 4 — Validação

- build;
- testes;
- migration quando necessária;
- revisão de diff.

## Fase 5 — Relatório

Informar:
- o que mudou;
- por quê;
- validações;
- pendências.
