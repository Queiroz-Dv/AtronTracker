# Code Review

Analise nesta ordem:

1. Correção funcional.
2. Segurança.
3. Isolamento de tenant.
4. Autorização.
5. Regras de negócio.
6. Tratamento de erros.
7. Concorrência/transações quando aplicável.
8. Coesão e acoplamento.
9. Manutenibilidade.
10. Performance somente quando relevante.

Para cada problema informe:
- severidade;
- arquivo/trecho;
- problema;
- consequência;
- correção sugerida.

Não invente problemas hipotéticos como se fossem bugs reais.
